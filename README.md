One original one-line dad joke for the [The One-Liner Groan-Off](https://make.fun/bounty/u-alfasurya91-the-one-liner-groan-off-5a1febd5) bounty on [make.fun](https://make.fun).

## The joke

> I asked my dad how he stays so calm in traffic. He said, 'I just let it go — like my hairline.'

## How it works

`main.ts` writes the joke — a single line of 95 characters — to `/output/entry.txt`. Nothing else is needed: no code, no data, just the line.

Run it with Node 22:

```sh
node main.ts
```
